# docs/

VitePress で組む説明・リファレンスサイト。GitHub Pages
（https://shuji-bonji.github.io/rfcxml-mcp/）に `.github/workflows/docs.yml` が配備する。

## 作り方

ルートから:

```bash
npm run build           # dist/ を作る（生成スクリプトが dist/tools/definitions.js を読む）
npm run docs:generate   # 生成ページを書き出す
npm run docs:dev        # ローカルで見る
npm run docs:build      # docs:generate → vitepress build（docs/.vitepress/dist/）
```

`docs/` は独立した npm パッケージで、初回は `npm --prefix docs install` が要る
（ルートの devDependencies には vitepress を入れない）。

## 手で書くページと、生成するページ

| 種類 | ファイル |
|---|---|
| 手書き | `index.md`, `guide/install.md`, `guide/accuracy.md`, `ja/index.md`, `ja/guide/install.md`, `ja/guide/accuracy.md` |
| 生成 | `reference/tools.md`, `reference/instructions.md`, `reference/examples.md` と `ja/reference/` の同名 3 本 |

生成ページは `scripts/generate.mjs` が書く。冒頭に
`<!-- generated by docs/scripts/generate.mjs — do not edit -->` がある。
**手で編集しない**。直したいときは読み元（`src/tools/definitions.ts`、`src/server.ts`、
`tests/snapshot/`）か `generate.mjs` を直す。

生成した .md は git に入れる（差分で内容の変化が見えるようにするため）。

読み元:

- `dist/tools/definitions.js` → `reference/tools.md`
- `src/server.ts` の `INSTRUCTIONS` → `reference/instructions.md`
- `tests/snapshot/cases.mjs` + `tests/snapshot/__snapshots__/*.txt` → `reference/examples.md`

`guide/accuracy.md` は `CLAUDE.md` の該当節から、`guide/install.md` と `index.md` は
`README.md` / `README.ja.md` から手で取る。そちらを変えたら追随させる。
